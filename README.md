# Песочница №8 для VPS и Nginx Proxy Manager

Контейнер раздаёт один готовый HTML через Nginx. Сертификат и маршрутизацию домена настраиваете в своём Nginx Proxy Manager; отдельный прокси здесь не поднимается. Встроенные стили, JavaScript и логотипы находятся в HTML.

## Запуск

Распакуйте архив на VPS, войдите в папку `task8-docker` и выполните:

```sh
docker compose up -d --build
```

По умолчанию страница доступна по HTTP на порту VPS `8088`. Если порт занят:

```sh
PORT=8090 docker compose up -d --build
```

Проверка:

```sh
docker compose ps
curl -I http://127.0.0.1:8088/
curl -I http://127.0.0.1:8088/sandbox8/
```

Оба адреса должны вернуть `200`. Конфигурация поддерживает корень домена и произвольный путь, например `/sandbox8/`: переписывать префикс в NPM не требуется. Страница не меняет свой URL и не использует отдельные локальные ресурсы.

## Что указать в Nginx Proxy Manager

Для Proxy Host или Custom Location `/sandbox8/`:

- Scheme: `http`.
- Forward Hostname / IP: адрес VPS, доступный из контейнера NPM.
- Forward Port: `8088` (или выбранный PORT).
- SSL: настраивается в NPM.

Если NPM сам работает в Docker, `127.0.0.1` внутри него обычно указывает на контейнер NPM, а не на VPS. Используйте доступный адрес VPS либо общую Docker-сеть.

Опционально можно подключить песочницу к существующей сети NPM:

```sh
docker network connect ИМЯ_СЕТИ_NPM shkolkovo-task8
```

Тогда upstream в NPM — `shkolkovo-task8`, порт `80`. При пересоздании контейнера командой compose ручное подключение к сети нужно повторить. Основной вариант выше с IP VPS и портом 8088 этого не требует.

Для привязки опубликованного порта к конкретному интерфейсу задайте BIND_IP, например `BIND_IP=127.0.0.1`, но только если NPM действительно имеет доступ к этому интерфейсу.

## Обновление HTML

Замените `index.html` и пересоберите контейнер:

```sh
docker compose up -d --build
```

Остановка:

```sh
docker compose down
```

## Прогресс

На собственном домене доступен весь интерфейс и расчёты. SDK Школково остаётся подключённым согласно AGENTS.md, но без платформы сохранение недоступно: страница показывает соответствующее сообщение. Контейнер не содержит серверного хранилища прогресса.

## Проверка сборки
