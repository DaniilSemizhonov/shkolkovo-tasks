# Песочница №6 для VPS

Запуск: `docker compose up -d --build`. HTTP-порт VPS по умолчанию — 8086.
Для другого порта: `PORT=8090 docker compose up -d --build`.
В Nginx Proxy Manager укажите HTTP, доступный из NPM адрес VPS и порт 8086.
Внутри Docker адрес 127.0.0.1 относится к самому контейнеру.
Поддерживаются корень и произвольный путь, например /sandbox6/.
На собственном домене интерфейс работает без сохранения Школково.
Docker-образ в рабочей среде не запускался.
