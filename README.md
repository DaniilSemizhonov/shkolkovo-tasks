# Песочница №4 для VPS

Распакуйте архив, откройте папку `task4-docker` и выполните:

```sh
docker compose up -d --build
```

Песочница доступна на HTTP-порту 8084. Для другого порта запустите
`PORT=8094 docker compose up -d --build`.

Если используете Nginx Proxy Manager, укажите схему HTTP, доступный из NPM
адрес VPS и порт 8084. Страница открывается в корне домена или по пути
вроде `/sandbox4/`.

После замены `index.html` повторите команду запуска, чтобы пересобрать образ.
